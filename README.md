# DCL--mySQL-
trabalho SENAI

👤 Autor
Nome: Giovanni Allevi

Objetivo: Demonstrar na prática a criação de utilizadores, concessão de privilégios temporários, execução de operações CRUD e posterior revogação de acessos no MySQL.

📌 Resumo da Atividade
Criação da Infraestrutura: Criação do banco de dados escola_dcl e da tabela aluno.

Gestão de Utilizadores (DCL): Criação do utilizador aluno_bd com permissões limitadas.

Validação de Permissões: Teste dos comandos SELECT, INSERT, UPDATE e DELETE logado como aluno_bd.

Revogação e Bloqueio: Remoção de todas as permissões pelo administrador e verificação dos erros de acesso negado.
